# Data Structure Types Examples (Programmed in C++)
These are a few examples of Data Structure forms that I created as references.

## Linear
Linear data structure means conforming to any individual data sets that are in a single sequential row and format: 0 to (+oo)
Example (Linear Array): {1, 2, 3, 4, ...}

## Non-linear:
Any data structure that conforms to a child parent data format (i.e. Trees)
