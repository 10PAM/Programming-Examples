# These are the steps for compiling and linking this program using a compiler (GCC in this case); We can also use MSVC compiler for Windows, etc...

## CLI: 
Windows Terminal (Can also use Windows Powershell, etc...)

## MSVC Command:
$\color{lightgreen}\textsf{"g++ cppclass.cpp cppclass.h -o cppclass.exe"}$
NOTE: This command links cppclass.cpp and cppclass.h into an executable. More files can be added, or a single header file can be created to include all other imported and used files.

## Run Command:
$\color{lightgreen}\textsf{"./cppclass.exe"}$
